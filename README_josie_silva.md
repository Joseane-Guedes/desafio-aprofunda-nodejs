## Desafio aprofunda: Exercícios de Lógica com Node.js 🚀

Bem-vinda! 👋🏾
Essa é a minha solução para o **Desafio de Lógica com Node.js** do programa Aprofunda Pretalab 2025.
O desafio envolveu 10 exercícios que testam lógica, uso de funções, condicionais, laços de repetição e boas práticas com JavaScript no ambiente Node.js.

Aqui você encontrará um código limpo, funcional e escrito com muito carinho e atenção aos detalhes. 💡✨

---

## 🧩 Sobre o Desafio

Foram propostos 10 exercícios práticos com diferentes abordagens de lógica, sendo necessário resolvê-los utilizando JavaScript com Node.js.
Minha entrega buscou aplicar os princípios de **Clean Code**, com foco em **nomes descritivos**, **clareza no raciocínio** e **simplicidade na implementação**.

---

## ✍️ Exercícios Implementados

| Nº  | Descrição                            | Função                        |
| --- | ------------------------------------ | ----------------------------- |
| 1️⃣  | Imprimir números pares até N         | `imprimirPares(n)`            |
| 2️⃣  | Somar elementos de um array          | `somarArray(array)`           |
| 3️⃣  | Verificar se número é primo          | `ehPrimo(numero)`             |
| 4️⃣  | Executar FizzBuzz de 1 a 50          | `fizzBuzz()`                  |
| 5️⃣  | Contar vogais em uma string          | `contarVogais(texto)`         |
| 6️⃣  | Imprimir tabuada de um número        | `tabuada(numero)`             |
| 7️⃣  | Inverter uma string                  | `inverterString(texto)`       |
| 8️⃣  | Encontrar o maior número em um array | `encontrarMaiorNumero(array)` |
| 9️⃣  | Verificar se uma string é palíndromo | `ehPalindromo(texto)`         |
| 🔟  | Calcular média e exibir aprovação    | `calcularMedia(notas)`        |

---

## 🧠 Boas Práticas Aplicadas

- Uso de `for`, `reduce`, `match`, `Math.max` e `split/reverse/join`

- Nomes de funções verbais e expressivos

- Regex com suporte a acentuação para contar vogais corretamente

- Lógica otimizada para checar primos até √n

- Separação clara entre declaração e execução

- Código comentado quando necessário, sem excessos

---

## 🧪 Como executar

Para rodar o script e ver os testes no console:
